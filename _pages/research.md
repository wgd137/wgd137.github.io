My current work focuses on data-driven modeling for autonomous systems, environmental forecasting, and multimodal perception.

Spatio-Temporal Weather Analysis and Forecast
======

**Research Project, Sep. 2025 - Present**

I am developing a high-resolution meteorological benchmark based on ERA5 reanalysis data, focusing on wind speed forecasting in Southeast China's coastal zones.

- Built a data pipeline for large-scale grid meteorological data.
- Modeled complex spatio-temporal dependencies for data-driven forecasting.
- Evaluated deep learning baselines on HPC clusters using Slurm.

Robust Multimodal Object Detection via Spatial Feature Rectification
======

**Research Project, Jun. 2025 - Dec. 2025**

This project studies robust object detection under multimodal RGB and thermal sensing, especially when the sensors are affected by adverse conditions or spatial misalignment.

- Proposed a scale-modality decoupled interaction module.
- Used attention-guided feature-space augmentation to synthesize hard examples.
- Evaluated robustness on standard multimodal detection benchmarks.

Autonomous Mobile Robot Navigation System
======

**Coursework, Sep. 2025 - Dec. 2025**

I built a TurtleBot3 navigation stack using ROS2 and Python, with a focus on reactive behavior and reliable localization.

- Migrated control logic from finite state machines to behavior trees.
- Integrated AMCL for localization.
- Tuned PID controllers for smooth trajectory tracking.
